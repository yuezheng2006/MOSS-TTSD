## 🎯 使用指南

### **选择合适的场景**
1. **根据内容定位**: 选择与你的播客主题相符的场景
2. **考虑受众群体**: 不同场景适合不同的听众
3. **参考对话风格**: 每个场景都有其独特的表达风格

### **自定义修改**
1. **替换具体内容**: 保持对话结构，更换具体话题
2. **调整角色设定**: 根据需要修改说话者身份
3. **适配语言风格**: 调整正式程度和表达方式

### **质量优化建议**
1. **保持对话自然**: 避免过于书面化的表达
2. **控制单句长度**: 每句话不要过长，便于理解
3. **增加互动元素**: 适当的提问和回应让对话更生动

## 🛠️ 扩展建议

### **创建新场景**
1. **确定主题方向**: 选择具体的细分领域
2. **设计角色对话**: 确保角色身份匹配专业度
3. **编写自然对话**: 模拟真实的对话交流
4. **测试生成效果**: 验证音频质量和自然度

### **场景组合使用**
- **系列节目**: 同一主题下的多个不同角度讨论
- **跨界对话**: 结合不同场景的元素创新表达
- **深度专题**: 基于一个场景展开系列深入讨论

## 📁 文件使用方法

### **在界面中使用**
1. 将场景文件复制到项目目录
2. 在Gradio界面中点击"上传文件"
3. 选择对应的场景jsonl文件
4. 根据需要修改内容后生成

### **命令行使用**
```bash
python inference.py --jsonl scenarios/科技播客_AI发展.jsonl --output_dir output/
```

### **自定义开发**
```python
# 读取场景文件
with open('scenarios/科技播客_AI发展.jsonl', 'r') as f:
    scenario = json.loads(f.read())
    
# 修改内容
scenario['text'] = "你的自定义对话内容..."

# 继续处理...
```
