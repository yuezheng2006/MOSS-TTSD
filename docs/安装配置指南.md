# 🛠️ MOSS-TTSD 安装配置指南

## 📋 系统要求

### **💻 硬件要求**
| 组件 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **内存** | 8GB RAM | 16GB+ RAM |
| **存储** | 20GB 可用空间 | 50GB+ SSD |
| **GPU** | 可选 (CPU模式支持) | NVIDIA GPU + CUDA |
| **系统** | macOS/Linux/Windows | macOS 12+ / Ubuntu 20+ |

### **🔧 软件要求**
- **Python**: 3.8+ (推荐 3.9-3.11)
- **Git**: 用于克隆代码库
- **网络**: 下载模型需要稳定网络连接

## 🚀 快速安装 (推荐)

### **步骤 1: 克隆项目**
```bash
# 克隆MOSS-TTSD项目
git clone https://github.com/OpenMOSS/MOSS-TTSD.git
cd MOSS-TTSD
```

### **步骤 2: 创建虚拟环境**

**方案A: 使用conda (推荐)**
```bash
# 创建conda环境
conda create -n moss_ttsd_env python=3.9 -y
conda activate moss_ttsd_env
```

**方案B: 使用venv**
```bash
# 创建虚拟环境
python -m venv moss_ttsd_env

# 激活环境
# macOS/Linux:
source moss_ttsd_env/bin/activate
# Windows:
moss_ttsd_env\Scripts\activate
```

### **步骤 3: 安装Python依赖**
```bash
# 升级pip
pip install --upgrade pip

# 安装核心依赖
pip install torch torchaudio transformers gradio numpy
pip install accelerate PyPDF2 beautifulsoup4 soundfile librosa
pip install tqdm requests openai PyYAML einops huggingface_hub pydub

# macOS用户特别注意 - 条件安装liger_kernel
if [[ "$OSTYPE" == "darwin"* ]]; then
  echo "⚠️ macOS系统检测到，跳过liger_kernel安装"
else
  pip install liger_kernel
fi

# 或者直接使用requirements.txt（推荐）
pip install -r requirements.txt
```

### **步骤 4: 下载模型权重**
```bash
# 创建模型权重目录
mkdir -p XY_Tokenizer/weights

# 下载XY_Tokenizer模型权重
huggingface-cli download fnlp/XY_Tokenizer_TTSD_V0 xy_tokenizer.ckpt \
  --local-dir ./XY_Tokenizer/weights/

# 验证文件是否下载成功
ls -la XY_Tokenizer/weights/
```

### **步骤 5: 验证安装**

### **🏗️ 模型下载详解**

#### **方法1: 使用huggingface-cli (推荐)**
```bash
# 如果没有安装huggingface_hub
pip install huggingface_hub

# 登录HuggingFace (如果需要)
huggingface-cli login

# 下载模型权重
huggingface-cli download fnlp/XY_Tokenizer_TTSD_V0 xy_tokenizer.ckpt \
  --local-dir ./XY_Tokenizer/weights/ \
  --resume-download
```

#### **方法2: 使用Python脚本**
```python
# download_models.py
from huggingface_hub import hf_hub_download
import os

def download_model():
    """下载XY_Tokenizer模型权重"""
    print("🔄 开始下载模型权重...")
    
    # 确保目录存在
    os.makedirs("XY_Tokenizer/weights", exist_ok=True)
    
    try:
        # 下载模型文件
        file_path = hf_hub_download(
            repo_id="fnlp/XY_Tokenizer_TTSD_V0",
            filename="xy_tokenizer.ckpt",
            local_dir="./XY_Tokenizer/weights",
            resume_download=True
        )
        print(f"✅ 模型下载成功: {file_path}")
        return True
    except Exception as e:
        print(f"❌ 模型下载失败: {e}")
        return False

if __name__ == "__main__":
    download_model()
```

```bash
# 运行下载脚本

```

### **🔧 环境健康检查脚本**
```python
# health_check.py
def check_environment():
    """检查MOSS-TTSD环境配置"""
    print("🔍 MOSS-TTSD 环境健康检查")
    print("=" * 50)
    
    checks = []
    
    # 1. Python版本检查
    import sys
    python_version = sys.version_info
    if python_version >= (3, 8):
        checks.append(("✅", f"Python版本: {python_version.major}.{python_version.minor}.{python_version.micro}"))
    else:
        checks.append(("❌", f"Python版本过低: {python_version.major}.{python_version.minor}"))
    
    # 2. 核心包检查
    required_packages = [
        "torch", "torchaudio", "transformers", "gradio", 
        "numpy", "soundfile", "librosa", "huggingface_hub"
    ]
    
    for package in required_packages:
        try:
            module = __import__(package)
            version = getattr(module, "__version__", "unknown")
            checks.append(("✅", f"{package}: {version}"))
        except ImportError:
            checks.append(("❌", f"{package}: 未安装"))
    
    # 3. 可选包检查
    optional_packages = ["liger_kernel", "flash_attn"]
    for package in optional_packages:
        try:
            __import__(package)
            checks.append(("🔶", f"{package}: 已安装 (可选)"))
        except ImportError:
            checks.append(("🔶", f"{package}: 未安装 (可选)"))
    
    # 4. 设备检查
    try:
        import torch
        if torch.cuda.is_available():
            checks.append(("✅", f"CUDA: 可用 (设备数量: {torch.cuda.device_count()})"))
        else:
            checks.append(("🔶", "CUDA: 不可用，将使用CPU模式"))
    except:
        checks.append(("❌", "PyTorch: 检查失败"))
    
    # 5. 模型文件检查
    import os
    model_path = "XY_Tokenizer/weights/xy_tokenizer.ckpt"
    if os.path.exists(model_path):
        size = os.path.getsize(model_path) / (1024**3)  # GB
        checks.append(("✅", f"模型权重: 已下载 ({size:.1f}GB)"))
    else:
        checks.append(("❌", "模型权重: 未下载"))
    
    # 6. 示例文件检查
    example_files = ["examples/examples.jsonl", "examples/zh_spk1_moon.wav", "examples/zh_spk2_moon.wav"]
    for file_path in example_files:
        if os.path.exists(file_path):
            checks.append(("✅", f"示例文件: {file_path}"))
        else:
            checks.append(("⚠️", f"示例文件缺失: {file_path}"))
    
    # 输出检查结果
    for status, message in checks:
        print(f"{status} {message}")
    
    # 总结
    success_count = sum(1 for status, _ in checks if status == "✅")
    total_critical = sum(1 for status, _ in checks if status in ["✅", "❌"])
    
    print("\n" + "=" * 50)
    if success_count >= total_critical * 0.8:
        print("🎉 环境配置良好，可以开始使用MOSS-TTSD！")
        return True
    else:
        print("⚠️ 环境配置有问题，请检查上述失败项目")
        return False

if __name__ == "__main__":
    check_environment()
```

```bash

python health_check.py
```

## 🔧 故障排除

### **常见问题及解决方案**

#### **🐍 Python相关问题**

**问题1: `python: command not found`**
```bash
# 解决方案 - 安装Python
# macOS
brew install python

# Ubuntu
sudo apt install python3 python3-pip

# 或者使用python3
python3 --version
```

**问题2: pip安装依赖失败**
```bash
# 解决方案 - 升级pip并使用清华镜像
pip install --upgrade pip
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple torch transformers gradio
```

#### **📦 依赖安装问题**

**问题3: `liger_kernel` 安装失败 (macOS常见)**
```bash
# 这是正常现象，项目已经做了兼容处理
echo "⚠️ liger_kernel安装失败是正常的，项目会自动使用标准实现"
```

**问题4: `flash-attn` 编译失败**
```bash
# 解决方案 - 跳过flash-attention，使用其他实现
python inference.py --attn_implementation sdpa  # 或者 eager
```

**问题5: PyTorch CUDA版本不匹配**
```bash
# 解决方案 - 重新安装对应CUDA版本的PyTorch
pip uninstall torch torchaudio
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu118
```

#### **🗂️ 模型下载问题**

**问题6: 模型下载速度慢或失败**
```bash
# 解决方案A - 使用代理
export HF_ENDPOINT=https://hf-mirror.com
huggingface-cli download fnlp/XY_Tokenizer_TTSD_V0 xy_tokenizer.ckpt --local-dir ./XY_Tokenizer/weights/

# 解决方案B - 分段下载
huggingface-cli download fnlp/XY_Tokenizer_TTSD_V0 xy_tokenizer.ckpt --local-dir ./XY_Tokenizer/weights/ --resume-download
```

**问题7: 权限问题**
```bash
# 解决方案 - 修复权限
chmod -R 755 XY_Tokenizer/
mkdir -p XY_Tokenizer/weights
```

#### **🚀 运行时问题**

**问题8: 内存不足**
```bash
# 解决方案 - 使用较低精度
python inference.py --dtype fp16  # 或者 bf16

# 减少批处理大小
# 修改generation_utils.py中的batch_size参数
```

**问题9: Gradio界面无法访问**
```bash
# 解决方案 - 检查端口和防火墙
# 使用localhost而不是0.0.0.0
python enhanced_podcast_ui.py

# 在浏览器访问: http://localhost:7861
```

**问题10: 音频生成质量差**
```bash
# 解决方案 - 优化参数
python inference.py --use_normalize --dtype fp32 --attn_implementation eager
```
