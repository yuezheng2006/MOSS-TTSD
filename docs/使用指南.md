# 🎙️ MOSS-TTSD 播客生成器 - 使用指南

## 🚀 快速开始

### 启动服务
```bash
# 方法1: 一键启动
python start_ui.py

# 方法2: 直接启动界面
python enhanced_podcast_ui.py

# 方法3: 自动打开浏览器
python open_ui.py
```

**访问地址**: http://localhost:7861

### 三步生成播客
1. 🎭 **选择场景** → 从下拉菜单选择播客类型
2. 📥 **加载内容** → 点击"加载场景"自动填充
3. 🎬 **生成播客** → 点击主按钮开始制作

## 🎨 界面功能

### 快速操作区
- **🎭 场景选择器** - 6种预设播客场景
- **📥 加载场景** - 一键加载选中场景的完整内容
- **🎧 默认音频** - 快速加载两个说话者的参考音频
- **🗑️ 清空内容** - 一键重置所有输入内容
- **🎲 随机示例** - 随机选择并加载一个场景

### 说话者设置
- **音频上传** - 支持WAV/MP3/FLAC格式
- **参考文本** - 必须与音频内容完全匹配
- **🎧 小按钮** - 单独加载该说话者的默认音频

### 生成设置
- **文本标准化** - 推荐开启，提高生成质量
- **随机种子** - 控制生成的随机性

## 📝 使用技巧

### 文本编写规范
```
✅ 好的示例:
[S1]大家好，欢迎收听今天的播客。
[S2]你好，我很高兴来到这里。
[S1]今天我们来聊聊一个有趣的话题。

❌ 避免的问题:
[S1]大家好，欢迎收听今天的播客，我是主播小雨，今天天气很好，我们来聊聊一个非常有意思的话题...（过长单句）
```

### 音频录制要求
- **环境**: 安静室内，无回音
- **设备**: 清晰麦克风，距离20-30cm
- **时长**: 15-25秒最佳
- **内容**: 自然朗读，语调丰富
- **格式**: WAV, MP3, FLAC

### 性能优化
- **硬件**: 推荐GPU加速，CPU模式也可用
- **内存**: 确保16GB+内存可用
- **文件**: 参考音频不要过大（<10MB）

## 🔧 故障排除

### 常见问题解决

#### 界面无法访问
```bash
# 检查服务状态
curl http://localhost:7861

# 重启服务
pkill -f enhanced_podcast_ui.py
python enhanced_podcast_ui.py
```

#### 生成失败
1. **检查音频格式** - 确保是WAV/MP3/FLAC
2. **检查文本格式** - 确认使用了[S1]和[S2]标记
3. **检查参考文本** - 必须与音频内容匹配
4. **检查内存** - 确保有足够的可用内存

#### 生成速度慢
1. **硬件升级** - 使用GPU替代CPU
2. **减少长度** - 缩短单次生成的对话长度
3. **关闭其他应用** - 释放更多内存和CPU

#### 音质问题
1. **提高参考音频质量** - 使用更清晰的录音
2. **精确参考文本** - 确保文本与音频完全一致
3. **调整生成参数** - 尝试不同的随机种子

## 🛠️ 高级功能

### 自定义场景
1. 复制现有场景文件到 `scenarios/` 目录
2. 修改对话内容和角色设定
3. 保存为新的JSONL文件
4. 在界面中选择使用

### 命令行使用
```bash
# 批量处理
python inference.py --jsonl scenarios/科技播客_AI发展.jsonl --output_dir output/

# 自定义参数
python inference.py --jsonl your_script.jsonl --output_dir output/ --seed 42 --dtype fp32
```

### API集成
参考 `use_api.py` 了解API调用方式，支持REST API接口集成。
