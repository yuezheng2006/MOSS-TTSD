# 🎛️ MOSS-TTSD 生成参数详解

## 📊 当前可用参数

### **基础参数**
| 参数名 | 类型 | 默认值 | 说明 | 影响 |
|--------|------|--------|------|------|
| `seed` | int | None | 随机种子 | 控制生成的随机性和可重复性 |
| `use_normalize` | bool | False | 文本标准化 | 提高文本处理质量，建议开启 |
| `dtype` | str | "bf16" | 模型精度 | fp32 > fp16 > bf16 (质量vs速度) |
| `attn_implementation` | str | "flash_attention_2" | 注意力实现 | 影响推理速度和内存占用 |

### **高级生成参数 (需扩展)**
| 参数名 | 类型 | 推荐值 | 说明 | 影响效果 |
|--------|------|--------|------|---------|
| `temperature` | float | 1.0 | 温度控制 | 🎯 **语气自然度** |
| `top_k` | int | 50 | Top-K采样 | 🎯 **词汇多样性** |
| `top_p` | float | 0.9 | Nucleus采样 | 🎯 **表达流畅度** |
| `repetition_penalty` | float | 1.1 | 重复惩罚 | 🎯 **避免重复表达** |
| `max_length` | int | 16384 | 最大长度 | 🎯 **生成时长控制** |
| `do_sample` | bool | True | 是否采样 | 🎯 **确定性vs随机性** |

## 🎯 参数效果详解

### **🌡️ Temperature (温度)**
```python
# 控制语气的自然度和随机性
temperature = 0.7   # 更稳定、保守的语气
temperature = 1.0   # 平衡的自然语气 (推荐)
temperature = 1.3   # 更多样、活泼的语气
```

**影响**:
- **低温 (0.5-0.8)**: 语气更稳定、正式，适合新闻播报
- **中温 (0.9-1.1)**: 自然对话语气，适合大多数播客
- **高温 (1.2-1.5)**: 活泼、富有变化，适合娱乐节目

### **🔝 Top-K & Top-P**
```python
# 控制词汇选择的多样性
top_k = 20     # 保守，词汇选择有限
top_k = 50     # 平衡，推荐值
top_k = 100    # 激进，词汇更多样

top_p = 0.8    # 较保守的表达
top_p = 0.9    # 推荐值
top_p = 0.95   # 更丰富的表达
```

### **🔄 Repetition Penalty**
```python
# 避免重复表达
repetition_penalty = 1.0    # 无惩罚
repetition_penalty = 1.1    # 轻微避免重复 (推荐)
repetition_penalty = 1.2    # 强烈避免重复
```

## 🛠️ 参数调优指南

### **语气控制**
- **温和语气**: 降低temperature (0.7-0.9)
- **激情语气**: 提高temperature (1.1-1.3)
- **专业语气**: 降低top_p (0.8-0.85)
- **随性语气**: 提高top_p (0.9-0.95)

### **语速感知**
虽然无法直接控制语速，但可以通过以下方式影响：
- **较慢感知**: 降低temperature，增加repetition_penalty
- **较快感知**: 提高temperature，降低repetition_penalty
- **停顿控制**: 在文本中适当添加标点符号

### **情感表达**
- **平静**: temperature=0.8, top_p=0.85
- **兴奋**: temperature=1.2, top_p=0.95
- **严肃**: temperature=0.7, top_p=0.8
- **幽默**: temperature=1.1, top_p=0.92

### **参数传递**
在`generation_utils.py`中修改`model.generate()`调用：

```python
# 添加自定义生成配置
from transformers import GenerationConfig

generation_config = GenerationConfig(
    max_length=max_length,
    temperature=temperature,
    top_k=top_k,
    top_p=top_p,
    repetition_penalty=repetition_penalty,
    do_sample=True,
    layers=[
        {
            "temperature": temperature,
            "top_k": top_k, 
            "top_p": top_p,
            "repetition_penalty": repetition_penalty
        } for _ in range(8)  # 8个通道
    ]
)

outputs = model.generate(
    input_ids=input_ids,
    attention_mask=attention_mask,
    generation_config=generation_config
)
```

## 📈 调试建议

### **参数测试方法**
1. **固定seed**: 确保可重复对比
2. **单一变量**: 每次只调整一个参数
3. **AB测试**: 对比不同参数组合的效果
4. **主观评估**: 多人评测语气自然度

### **常见问题**
- **生成过于重复**: 增加`repetition_penalty`
- **语气太僵硬**: 提高`temperature`
- **表达不够丰富**: 增加`top_k`和`top_p`
- **语气不够稳定**: 降低`temperature`
